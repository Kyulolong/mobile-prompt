# 출시 체크리스트 — iOS 1.3.0 · Android 1.0.0 (2026-10-27)

두 콘솔 모두 웹에서 손으로 한다. 붙여 넣을 문구는 파일에 있고, 아래는 **순서와 클릭할 곳**만 적는다.

## A. App Store Connect — 1.3.0 (19)

빌드 19(앱 안 퍼플즈 안내 문구를 사실대로 고친 것)가 최종이다. 18은 쓰지 않는다. 처리에 10~30분 걸리고, 끝나면 메일이 온다.

1. appstoreconnect.apple.com → 나의 앱 → **보이스 프롬프터** → 왼쪽 **iOS 앱** 옆 `+` → 새 버전 **`1.3.0`** (바이너리와 같은 값. 지금 라이브가 "1.2"로 보이는 어긋남을 여기서 끝낸다).
2. **빌드** 섹션 → `+` → **1.3.0 (19)** 선택. 수출 규정 질문이 뜨면 "아니요" (`ITSAppUsesNonExemptEncryption = NO`가 이미 박혀 있어 보통 안 뜬다).
3. **한국어** 탭: `store/listing-1.3.md`의 한국어 자료로 교체 — 부제목(23자), 프로모션 텍스트, 키워드, 설명, **이번 버전의 새로운 기능**(1.3.0 릴리스 노트). 스크린샷은 1.2 그대로.
4. **English (U.S.)** 탭: 같은 파일의 영어 자료.
5. **앱 심사 정보 → 메모**: 「다른 앱이 `voiceprompter://` URL 스킴이나 공유 시트로 대본 텍스트를 넘길 수 있고, 녹화 결과는 사용자가 공유 시트로 내보냅니다. 서버 통신·계정 없음.」
6. **앱 개인정보**: 변경 없음("데이터를 수집하지 않음"). 확인만.
7. 버전 출시: **수동 출시** 권장(승인 후 원하는 시점에 공개). 저장 → **심사에 추가** → **심사 제출**.

심사 통과 후: 출시 버튼. 이후 공개 스토어 `version`이 `1.3.0`으로 보이면 끝.

### B-3. 내부 테스트 → 프로덕션

1. 왼쪽 **테스트 → 내부 테스트** → **새 버전 만들기**.
2. **앱 서명**: Google Play 앱 서명 사용(기본). 업로드한 AAB의 키가 업로드 키로 등록된다.
3. AAB 업로드: `android/app/build/outputs/bundle/release/app-release.aab` (201MB, 에셋팩 포함 — 업로드 후 "모델" 에셋팩이 같이 보인다). 버전 이름 `1.3.0`, 코드 1 (iOS와 번호를 맞췄다).
4. 출시 노트: `store/android-listing.md`의 출시 노트(ko·en).
5. 테스터: **이메일 목록 만들기** → 본인 Google 계정 → 저장 → 버전 검토 → **내부 테스트로 출시 시작**.
6. 테스터 링크(`play.google.com/apps/internaltest/...`)를 갤럭시에서 열어 설치. ⚠️ 지금 갤럭시에 깔린 앱은 업로드 키 서명이라 **먼저 삭제**해야 설치된다.
7. 실기기에서 확인: 음성 따라가기, 녹화·갤러리 저장, 한국어/영어 전환, 딥링크(`adb shell "am start -a android.intent.action.VIEW -d 'voiceprompter://script?s=%EC%95%88%EB%85%95&autostart=1'"`).
8. 이상 없으면 **프로덕션 → 새 버전 만들기 → 내부 테스트에서 버전 가져오기** → 국가 선택(대한민국 + 전체) → 검토 제출. 신규 앱 첫 심사는 보통 1~7일.

### B-4. 올리기 전 한 번 더

- `teaminpact.com/pages/privacy` 본문을 `store/privacy.html`(iOS·Android 공용, 2026-10-26)로 교체했는가. 지금은 iOS 전용 옛 문구가 떠 있다. 심사 블로커는 아니지만 Android 문구가 없다.
- Play 콘솔 **앱 정보 → 광고 ID**: "이 앱은 광고 ID를 사용하지 않음" (AdMob 없음).
