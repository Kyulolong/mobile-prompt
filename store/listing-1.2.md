# 1.2.0 스토어 자료

> 참고: 1.1은 이미 출시됨. 1.2 = 아래 기존 항목 + SRT 자막 + 혼합 언어 + 안정화.

## 한국어 — "이번 버전의 새로운 기능" (릴리스 노트)

```
• 자막(SRT) 자동 생성 — 음성 따라가기로 녹화하면, 언제 어떤 문장을 읽었는지 앱이 이미 알고 있어요. 녹화가 끝나면 자막 파일이 자동으로 만들어지고, 저장 알림에서 바로 공유할 수 있어요.
• 혼합 언어 대본 — 한국어 대본 속 영어 문장(또는 그 반대)도 자동으로 인식 언어를 전환하며 따라가요.
• 화면 흔들림 근본 수정 — 읽는 중 화면이 앞뒤로 튀던 문제를 원천 차단했어요.
• 하이라이트 기본색이 초록(#8FFF00)으로 바뀌고, 앱 아이콘도 새로워졌어요.
• 대본 라이브러리 — 대본을 여러 개 저장하고 목록에서 골라 쓸 수 있어요. 스와이프로 삭제, + 버튼으로 새 대본.
• 공유로 가져오기 — 메모·메신저 등 어디서든 텍스트를 공유하면 새 대본으로 들어와요.
• 녹화 카운트다운 — 녹화 버튼을 누르면 3·2·1 후에 시작돼요.
• 영어 지원 — 영어 대본을 넣으면 자동으로 영어 음성인식으로 전환되고, 영어 UI도 지원해요.
• 언어 설정 — 설정에서 앱 언어와 인식 언어를 직접 고를 수 있어요. 인식 언어와 대본 언어가 다르면 화면에서 한 번에 전환할 수 있게 안내해 드려요.
• 더 편한 설정 — 홈 화면에서도 설정을 열 수 있고, 촬영 중 설정은 반만 올라와 화면을 가리지 않아요.
• 대본 정리 — 목록에서 대본을 길게 눌러 여러 개를 한 번에 삭제할 수 있어요.
```

## English (U.S.) 로컬라이제이션

- 이름: `Voice Prompter`
- 부제목(30자): `A teleprompter that follows you`
- 프로모션 텍스트: `Read at your own pace — the script follows your voice in real time. Record clean selfie videos with no text overlay.`
- 키워드(100자): `teleprompter,prompter,script,voice,speech,camera,record,reels,shorts,vlog,creator,autocue`

### 설명 (Description)

```
Voice Prompter listens to your voice and follows exactly where you are in the script — no fixed scroll speed to fight with.

READS WITH YOU
• Speak faster or slower — the screen keeps your place
• Pause, and it waits. Ad-lib, and it doesn't get lost
• Skip a paragraph and it catches up in about a second
• Numbers match however you say them (2025, 30%, …)

RECORD WHILE YOU READ
• See yourself with the front camera while the script floats on top
• Recorded videos stay clean — no text is burned in
• 3·2·1 countdown, recording badge, videos saved to your photo library

MADE FOR CREATORS
• Script library — keep as many scripts as you need
• Share text from any app to import it as a script
• Auto-scroll mode with speed control when you don't need the mic
• Highlight color options, mirror mode, adjustable script box and reading line
• Works in portrait and landscape (script hugs the camera side)

PRIVATE BY DESIGN
• No account, no ads, no analytics — nothing is collected
• Speech recognition runs on-device when supported
• Free.

Supports Korean and English scripts — the app detects the language automatically.
```

### 릴리스 노트 (What's New)

```
• Auto-generated subtitles (SRT) — record in voice-follow mode and the app already knows when you read each line; share the subtitle file right from the save alert
• Mixed-language scripts — English sentences inside a Korean script (and vice versa) switch recognition automatically
• Rock-solid scrolling — eliminated the screen bouncing at its source
• New green highlight (#8FFF00) and a refreshed app icon
• Script library — save multiple scripts and pick from a list
• Share text from any app to import it as a new script
• 3-2-1 countdown before recording starts
• English support — English scripts switch to English speech recognition automatically, with a fully localized UI
• Language settings — choose the app language and recognition language, with a gentle in-prompter suggestion when your script looks like a different language
• Easier settings — open Settings from the home screen; in the prompter it stays at half height so your view isn't covered
• Tidy your library — long-press a script to select and delete several at once
```
