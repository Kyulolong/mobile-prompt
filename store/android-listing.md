## 한국어 (ko-KR)

- 앱 이름(30자): `보이스 프롬프터`
- 간단한 설명(80자): `퍼플즈가 만든 목소리 따라오는 프롬프터. 프로젝트 소개 영상을 읽으면서 찍고 자막까지 한 번에.`

### 자세한 설명

```
보이스 프롬프터는 내 목소리를 듣고 지금 대본의 어디를 읽고 있는지 실시간으로 따라옵니다. 정해진 속도와 싸울 필요가 없어요.

프로젝트 소개 영상, 1분이면 돼요
• 데모데이·자기소개·포트폴리오 영상에 딱 맞아요
• 메모·문서 앱에서 대본을 공유하면 바로 읽을 수 있어요
• 읽으면서 찍고, 영상과 자막을 한 번에 공유해요

함께 읽어요
• 빨리 읽어도, 천천히 읽어도 화면이 내 자리를 지켜요
• 잠깐 멈추면 기다리고, 애드립을 해도 위치를 잃지 않아요
• 한 단락을 건너뛰어도 1초쯤이면 따라잡아요
• 숫자는 어떻게 읽어도 맞춰요 (2025년, 30퍼센트 …)

읽으면서 녹화해요
• 전면 카메라로 내 모습을 보면서, 대본은 그 위에 반투명으로 떠 있어요
• 녹화된 영상에는 글자가 찍히지 않아요
• 3·2·1 카운트다운, 녹화 표시, 영상은 갤러리(Movies/Voice Prompter)에 저장
• 음성 따라가기로 녹화하면 자막(SRT) 파일이 자동으로 만들어져요

크리에이터를 위해
• 대본 라이브러리 — 대본을 여러 개 저장해 두고 골라 써요
• 다른 앱에서 텍스트를 공유하면 바로 대본으로 들어와요
• 마이크가 필요 없을 땐 자동 스크롤 모드 + 속도 조절
• 하이라이트 색, 거울 모드, 글상자 크기와 읽는 줄 위치 조절
• 세로·가로 모드 지원 (가로에서는 대본이 카메라 쪽에 붙어요)

개인정보는 기기 안에
• 회원가입·광고·분석 도구 없음. 수집하는 정보가 없어요
• 음성인식은 전부 기기 안에서 처리돼요 (인터넷 없이도 동작)
• 무료

한국어와 영어 대본을 지원하고, 언어는 대본에서 자동으로 감지돼요.
```

### 출시 노트

```
• 첫 출시. 목소리를 따라오는 텔레프롬프터 + 셀피 녹화 + 자막(SRT) 자동 생성
• 음성인식이 기기 안에서 동작해요 — 인터넷 없이, 어떤 데이터도 밖으로 나가지 않아요
```

## English (en-US)

- Name: `Voice Prompter`
- Short description (80): `By Perplz. A teleprompter that follows your voice; record project intro videos.`

### Full description

```
Voice Prompter listens to your voice and follows exactly where you are in the script — no fixed scroll speed to fight with.

PROJECT INTRO VIDEOS IN A MINUTE
• Made for demo days, self-introductions, and portfolio videos
• Share a script from any notes or docs app and start reading right away
• Read, record, and share the video with its subtitles in one go

READS WITH YOU
• Speak faster or slower — the screen keeps your place
• Pause, and it waits. Ad-lib, and it doesn't get lost
• Skip a paragraph and it catches up in about a second
• Numbers match however you say them (2025, 30%, …)

RECORD WHILE YOU READ
• See yourself with the front camera while the script floats on top
• Recorded videos stay clean — no text is burned in
• 3·2·1 countdown, recording badge, videos saved to your gallery (Movies/Voice Prompter)

MADE FOR CREATORS
• Script library — keep as many scripts as you need
• Share text from any app to import it as a script
• Auto-scroll mode with speed control when you don't need the mic
• Highlight color options, mirror mode, adjustable script box and reading line
• Works in portrait and landscape (script hugs the camera side)

PRIVATE BY DESIGN
• No account, no ads, no analytics — nothing is collected
• Speech recognition runs entirely on your device, even offline
• Free

Supports Korean and English scripts — the language is detected automatically.
```

## 데이터 보안(Data safety) 양식 답

- 데이터 수집: **아니요** (수집·공유하는 사용자 데이터 없음)
- 데이터 암호화 전송 / 삭제 요청: 해당 없음
- 앱이 쓰는 권한: 카메라(프리뷰·녹화), 마이크(음성 따라가기·녹화 음성). 모두 기기 안에서만 처리. 퍼플즈 딥링크로 받은 대본도 기기에만 저장
- 개인정보처리방침 URL: `store/privacy.html`을 호스팅한 주소 (iOS와 공용, 2026-10 안드로이드 내용 추가)

## 앱 콘텐츠 선언

- 포그라운드 서비스/정확한 알람/사진·동영상 권한: 사용 안 함 (MediaStore로 저장하므로 저장소 권한 불필요)

## Play Console 절차

1. 모든 앱 → **앱 만들기**: 이름 `보이스 프롬프터`, 기본 언어 한국어, 앱, 무료
2. 대시보드 "앱 설정" 항목 채우기: 개인정보처리방침 URL, 앱 액세스, 광고(없음), 콘텐츠 등급 설문, 타겟층, 데이터 보안(위 답), 정부 앱 아님
3. 기본 스토어 등록정보: 위 한국어 자료 + 그래픽. 번역 추가 → English (United States) 자료
4. **테스트 → 내부 테스트** 트랙에 `app-release.aab` 업로드 → 테스터 이메일 등록 → 갤럭시 실기기에서 설치해 음성 따라가기·녹화·갤러리 저장 확인
5. 문제 없으면 프로덕션으로 승격. 첫 업로드 시 Play App Signing이 기본 적용되고, 업로드한 AAB의 서명 키가 업로드 키로 등록된다.
